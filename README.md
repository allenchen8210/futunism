# Futunism 台股研究雷達

以臺灣證券交易所（TWSE）盤後 OpenAPI 資料，自動建立上市股票研究清單的無依賴網頁。

公開網站：https://allenchen8210.github.io/futunism/

直接以瀏覽器開啟 `index.html` 即可。網頁會讀取：

- `STOCK_DAY_ALL`：最新上市股票收盤價、漲跌、成交量與成交金額
- `BWIBBU_ALL`：本益比、殖利率與股價淨值比

GitHub Actions 會在每個交易日收盤後更新官方資料快照。這是因為 TWSE
OpenAPI 未提供瀏覽器跨網域存取標頭，GitHub Pages 無法直接呼叫它。

## 評分

研究分數由合理本益比 25%、股價淨值比 10%、殖利率 25%、成交流動性 25%、單日價格行為 15% 組成。預設排除資料不完整、成交額過低、負盈餘，以及極端估值標的。介面中的門檻可即時調整。

這是候選股篩選器，不是買進指令或獲利保證。單日盤後數據無法取代財報、重大訊息、產業趨勢、歷史回測與個人風險評估。系統不連接券商，也不會下單。
